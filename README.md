# Tuk plus

A native Android client for the [Tuk](https://tukapp.co) food ordering service.

Status: phase 1 (browse) built; see [docs/phases/](docs/phases/README.md). See [docs/development.md](docs/development.md) to build.

- [docs/PLAN.md](docs/PLAN.md) – app plan: architecture, caching, screens, phases.
- [docs/api-reference.md](docs/api-reference.md) – the Tuk backend API, reverse engineered from the web app.
- [docs/design.md](docs/design.md) – the app's visual design (Material You, Rainbow lorikeet colors).

Tuk plus is not made by Tuk. Tuk gave permission to build it.
